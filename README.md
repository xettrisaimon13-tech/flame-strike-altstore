# FLAME STRIKE — AltStore source

Add this source in AltStore to install FLAME STRIKE on an iPhone.

Source URL:

```
https://raw.githubusercontent.com/xettrisaimon13-tech/flame-strike-altstore/main/altstore.json
```

## Install

1. Install AltStore on your iPhone (AltStore needs AltServer running on a Mac or Windows PC, plus your Apple ID).
2. Open AltStore → **Browse / Sources** → **+** → paste the source URL above.
3. Open **FLAME STRIKE** → **Free** → sign in with your Apple ID when asked.
4. Keep AltServer running on the same Wi-Fi network and refresh the app before 7 days pass, otherwise iOS deletes it.

Free Apple IDs allow 3 sideloaded apps at a time and the signature lasts 7 days. A paid Apple Developer account extends that to 1 year.

The IPA in the release is unsigned on purpose — AltStore re-signs it with your own certificate.
